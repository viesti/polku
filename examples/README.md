# Examples

Apps that a coding agent built from the blank [demo](../demo) through requests recorded with the Polku widget. Each directory is a complete copy of the demo app with the result in it, so you can run it, keep changing it through Polku, or rewrite it entirely without affecting the others.

| Example | What it is |
| --- | --- |
| [mood-game](mood-game) | A small game in which everyday activities change a character's mood |
| [terraria-clone](terraria-clone) | A side-scrolling 2D sandbox game with digging, caves, shops, slimes, a boss arena and outer space with aliens |
| [shopping-list](shopping-list) | Shopping lists with icons per item, stored in PostgreSQL |
| [roboland](roboland) | A blank frontend-only app served by shadow-cljs, on ports that let it run next to the others |

Each example's README says how to run it.
